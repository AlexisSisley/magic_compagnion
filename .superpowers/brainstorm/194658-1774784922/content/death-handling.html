Comportement à 0 PV — Death Handling

Quand un joueur atteint 0 PV (ou moins), que se passe-t-il ? Le problème actuel : l'app se "bloque" et empêche toute interaction.

Le flow proposé

1
Le joueur passe à ≤ 0
-3
Zone pulse en rouge
⚡ Les contrôles +/- restent ACTIFS
2
Overlay de confirmation
💀 Player 1 est à 0 PV
Ce joueur est-il éliminé ?
Non — corriger
Oui — éliminé
Apparaît après 2 secondes à ≤ 0 (pas immédiatement)
3a
Si "Non" → Continue
-3
Overlay disparaît
Le joueur peut ajuster ses PV normalement (+/-)
L'overlay ne réapparaîtra PAS
3b
Si "Oui" → Éliminé
💀
-3
Zone grisée
⟲ Reset
↩ Undo Elim.
Reset et Undo Élim. toujours accessibles

Question : le délai avant l'overlay

Quand le joueur passe à ≤ 0, quand afficher la confirmation ?

A

Immédiat

L'overlay apparaît dès que le joueur passe à ≤ 0. Réactif mais peut gêner si on tapait vite pour corriger.

B

Délai 2 secondes (recommandé)

Laisse le temps de corriger une erreur de tap. Si les PV remontent au-dessus de 0 pendant le délai, pas d'overlay.

C

Manuel uniquement

Pas d'overlay automatique. L'élimination se fait uniquement via le menu contextuel (long press → "Éliminer"). La zone pulse en rouge comme indicateur visuel.
